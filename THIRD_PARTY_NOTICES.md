# Dependencias y avisos de terceros

**Dependencias en tiempo de ejecución incorporadas al proyecto:** ninguna biblioteca externa. Frontend HTML5/CSS/JavaScript propios; servidor Python usa biblioteca estándar.

**Herramientas opcionales para desarrollar o verificar:** Python (PSF License), Node.js (licencia del proyecto Node.js), Playwright para Python (Apache-2.0) y Chromium (múltiples licencias abiertas). No forman parte del código de la aplicación ni se redistribuyen en este repositorio.

Se debe documentar y revisar el origen de cualquier dependencia agregada en versiones futuras.
