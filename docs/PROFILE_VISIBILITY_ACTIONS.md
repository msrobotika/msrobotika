Los repositorios originales conservan su historial; no deben volver a ocupar la navegación de instalación de la suite.

The profile presents AB Suite as the primary product: one launcher, nine tools and a shared download. Original repositories retain their history and should not replace the suite installation entry point.

- Ejecutar `python tools/check_featured_profile.py` al cambiar la portada. / Run the profile checker after changing the front page.
